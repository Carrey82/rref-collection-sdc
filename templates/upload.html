What happens next

  1. It joins the queue. Nothing is chased yet — there is no promise on record, which is exactly the state that earns a first message.
  2. Run today's scan. The invoice is aged, a tone is picked by rule, and one draft is written for it.
  3. Record a promise when the customer gives you a date. That is the only thing that stops the chasing.

Uploading does not call a model. The model is only reached at step 2, one invoice at a time — see the whole chain.

What this is not

No OCR, no PDF parsing, no camera. Those read the same six fields this form writes by hand, so they are an input method — not a separate feature. We built the ledger they feed, because that is the part nobody else has.
